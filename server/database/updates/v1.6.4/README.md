# v1.6.4 升级说明

## 变更

- DIY 分类页配置菜单名缩短:`分类页配置` → `分类配置`(4 字)
- 删除 v1.6.0 残留的占位/未实施按钮:
  - 页面装修「组件市场」
  - 模板中心「模板市场 / 排期日历 / 主题排期」
  - 底部导航「预览小程序 / 预览 APP」
- 商城风格「重置默认」按钮升级:确认后立即写库,而非仅重置本地表单

## 升级方式

```bash
mysql -uroot -p数据库名 < server/database/updates/v1.6.4/update.sql
```

## 回退

```sql
UPDATE `menus` SET `title` = '分类页配置' WHERE `id` = 1080;
```
